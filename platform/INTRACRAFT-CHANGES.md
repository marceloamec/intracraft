# IntraCraft changes to BIMCraft

This folder is [BIMCraft](https://github.com/IPedrax/BIMCraft) (MIT OR Apache-2.0), brought into the IntraCraft repository
as a git subtree ([ADR-0020](../docs/en/decisions/ADR-0020%20Rust%20Platform%20on%20BIMCraft%20with%20Three%20Modules.md)).
Upstream changes come in with:

```sh
git subtree pull --prefix=platform https://github.com/IPedrax/BIMCraft.git main --squash
```

IntraCraft adds its own crates in `sim/` and its own apps in `apps/intracraft*`. Every BIMCraft file IntraCraft changes is
listed here, with why, so that each change is marked as Apache-2.0 §4(b) asks and an upstream merge knows what to keep.

| File                  | Change                                                                                                                    |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| `.cargo/config.toml`  | Builds from the vendored sources in `vendor/` (source replacement); BIMCraft's `i18n` alias is kept                         |
| `Cargo.toml`          | `sim/*` added to the workspace members (IntraCraft's crates); Rapier, parry3d and `intracraft-physics` optimised in dev builds; Bevy, Avian and bevy_egui as workspace dependencies, Avian, parry3d-f64 and `intracraft-avian` optimised in dev builds (ADR-0026)                                                              |
| `crates/core/src/family.rs` | A form may `repeat` (`count` copies `step` apart, up to `MAX_REPEAT`: an array, for a conveyor's rollers and legs); `Kind::Text` (a text or a choice: IntraCraft's enums); an instance parameter takes its type's value before its own default, and a type may give one (a component inherits until it sets its own, A18 §4); only material parameters are checked as materials |
| `crates/core/src/model.rs` | `FORMAT` 11 → 12 for the above (no migration step); a component's text values are not checked as materials; `FORMAT` 12 → 13 for a form's `repeat` (no migration step) |
| `crates/core/src/schedule.rs` | Text parameters schedule as text fields |
| `crates/core/src/commands.rs` | The `family` command's docs name the `text` kind and a form's `repeat` |
| `crates/ui-egui/src/lib.rs` | The `Extension` hook (ADR-0025): an application's ribbon tabs after BIMCraft's, drawn with `ribbon_panel` and `ribbon_button`; a card beside the views; what it draws over the active view; `show_with`, `extension_tab`, `pick_extension_tab`, `open_view`; a selection doesn't raise the contextual tab while one of its tabs is picked; `big_button` and `list_row` paint any glyph; `Extension::hides_tab` leaves BIMCraft tabs out of the ribbon (IntraCraft hides the MEP tabs, ADR-0026) |
| `crates/ui-egui/src/properties.rs`, `crates/ui-egui/src/editor.rs` | Text parameters edited as text in Properties, Type Properties and the Family Editor |
| `crates/core/src/tests.rs`, `cad_tests.rs`, `dimension_tests.rs` | Format 13 in the format tests; a test of text parameters and of inherited instance values |
| `translations/**` | Line references regenerated by `cargo i18n update` (no message changed) |
