| Auslastung                          | Utilisation                          | Utilización                              | Zeitanteil, in dem eine Ressource arbeitet                                 |
| Belegungsprofil                     | Occupancy profile                    | Perfil de ocupación                      | Massive/hohle Zonen der Palette je Höhe; von Sensoren genutzt              |

| Kontinuierliche Kollisionserkennung | Continuous collision detection (CCD) | Detección continua de colisiones         | Verhindert, dass schnelle Körper dünne Hindernisse durchdringen            |
| Layout                              | Layout                               | Layout                                   | Platzierte und verbundene Komponenten: die einzige Quelle der Wahrheit     |

| Strahltest (Raycast)                | Raycast                              | Raycast                                  | Schnitttest eines Strahls mit Kollisionskörpern                            |
| Verriegelung                        | Interlock                            | Enclavamiento (interlock)                | Sicherheitsbedingung, die eine Aktion sperrt                               |
