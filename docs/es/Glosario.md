# Glosario

| Español                                  | English                          | Deutsch                             | Significado en IntraCraft                                                    |
| ---------------------------------------- | -------------------------------- | ----------------------------------- | ---------------------------------------------------------------------------- |
| Acumulación                              | Accumulation                     | Stau / Staubildung                  | Pallets esperando uno detrás de otro sobre un transportador                  |
| Acumulación sin presión (ZPA)            | Zero-pressure accumulation (ZPA) | Staudrucklose Förderung             | Cada zona solo arranca si la siguiente está libre; los pallets no se tocan   |
| Coeficiente de restitución (e)           | Coefficient of restitution (e)   | Stoßzahl (e)                        | Cociente entre velocidad de separación y de aproximación tras un impacto     |
| Coeficiente de rozamiento (μ)            | Coefficient of friction (μ)      | Reibkoeffizient (μ)                 | Cociente entre la fuerza tangencial máxima y la fuerza normal                |
| Colisionador                             | Collider                         | Kollisionskörper (Collider)         | Forma geométrica que el motor de física usa para los contactos               |
| Controlador                              | Controller                       | Steuerung                           | Reglas Si/Entonces que leen sensores y mandan actuadores                     |
| Cuerpo cinemático                        | Kinematic body                   | Kinematischer Körper                | Cuerpo movido por una velocidad impuesta; las fuerzas no lo afectan          |
| Detección continua de colisiones (CCD)   | Continuous collision detection   | Kontinuierliche Kollisionserkennung | Evita que cuerpos rápidos atraviesen obstáculos finos                        |
| Determinismo                             | Determinism                      | Determinismus                       | Mismos datos y semilla → resultados idénticos                                |
| Enclavamiento (interlock)                | Interlock                        | Verriegelung                        | Condición de seguridad que bloquea una acción                                |
| Flanco                                   | Edge (signal)                    | Flanke                              | Cambio de una señal booleana (subida 0→1, bajada 1→0)                        |
| Fotocélula                               | Photoelectric sensor (photoeye)  | Lichtschranke / Lichttaster         | Sensor de presencia por haz de luz                                           |
| Generador                                | Source                           | Quelle                              | Crea pallets                                                                 |
| Giratoria                                | Turntable                        | Drehtisch                           | Plataforma giratoria que cambia la dirección del flujo                       |
| Guía lateral                             | Guardrail / side guide           | Seitenführung                       | Carril estático que limita la posición lateral del pallet                    |
| Layout                                   | Layout                           | Layout                              | Componentes colocados y conectados: la única fuente de verdad                |
| Lista de eventos futuros                 | Future event list                | Ereignisliste                       | Cola de prioridad con los eventos programados                                |
| Mesa de cadenas                          | Chain conveyor                   | Kettenförderer                      | Transportador en el que el pallet apoya sobre ramales de cadena              |
| Mesa de rodillos                         | Roller conveyor                  | Rollenförderer                      | Transportador en el que el pallet apoya sobre rodillos motorizados           |
| Mesa de transferencia                    | Transfer table (chain transfer)  | Kettenumsetzer / Hubumsetzer        | Eleva cadenas entre rodillos para mover el pallet a 90°                      |
| Paso de rodillos                         | Roller pitch                     | Rollenteilung                       | Distancia entre ejes de rodillos                                             |
| Paso fijo                                | Fixed time step                  | Fester Zeitschritt                  | La física avanza en incrementos iguales (1/120 s)                            |
| Perfil de ocupación                      | Occupancy profile                | Belegungsprofil                     | Bandas macizas/huecas del pallet por altura; lo usan los sensores            |
| Preset                                   | Preset                           | Voreinstellung                      | Conjunto de valores de parámetros con nombre                                 |
| Puerto                                   | Port                             | Port / Übergabepunkt                | Punto donde un componente entrega o recibe un pallet                         |
| Puesta en marcha virtual                 | Virtual commissioning            | Virtuelle Inbetriebnahme            | Probar la lógica de control contra una planta simulada                       |
| Raycast                                  | Raycast                          | Strahltest (Raycast)                | Prueba de intersección de un rayo con colisionadores                         |
| Rendimiento                              | Throughput                       | Durchsatz                           | Pallets por unidad de tiempo                                                 |
| Semilla                                  | Seed                             | Startwert (Seed)                    | Valor inicial del generador pseudoaleatorio                                  |
| Simulación de eventos discretos (DES)    | Discrete-event simulation        | Ereignisdiskrete Simulation         | El reloj salta de evento en evento; modo 2D                                  |
| Sólido rígido                            | Rigid body                       | Starrkörper                         | Cuerpo indeformable con masa e inercia                                       |
| Sumidero                                 | Sink                             | Senke                               | Retira pallets del modelo                                                    |
| Superficie móvil / velocidad superficial | Surface velocity                 | Oberflächengeschwindigkeit          | Propiedad del contacto que hace que una superficie fija actúe como una cinta |
| Tabla inferior                           | Bottom board                     | Bodenbrett                          | Tabla baja del pallet que apoya en rodillos o cadenas                        |
| Taco                                     | Block (pallet)                   | Klotz                               | Bloque separador entre tablas inferiores y superiores                        |
| Tope (mecánico)                          | Stop (mechanical)                | Anschlag (Stopper)                  | Detiene el frente del pallet en una posición definida                        |
| Utilización                              | Utilisation                      | Auslastung                          | Fracción del tiempo en que un recurso trabaja                                |
