Diseño y simulación de transporte de pallets en tres módulos: Diseño (BIM), simulación discreta 2D y simulación física 3D.
Planung und Simulation von Palettenfördertechnik in drei Modulen: Planung (BIM), ereignisdiskrete 2D-Simulation, 3D-Physiksimulation.

## How this vault is organised · Cómo se organiza · Aufbau

Every language folder has the same structure and the same note numbers, so `T04` is the same topic in all three languages.
Cada carpeta de idioma tiene la misma estructura y la misma numeración: `T04` es el mismo tema en los tres idiomas.
Jeder Sprachordner hat dieselbe Struktur und Nummerierung: `T04` ist in allen drei Sprachen dasselbe Thema.
